# shadcn/ui

Component sources copied from the official new-york registry at https://ui.shadcn.com/r/styles/new-york/ on 2026-10-23, under the MIT license (https://github.com/shadcn-ui/ui/blob/main/LICENSE.md). TypeScript types were removed for this JavaScript app; imports use relative paths. Existing Tailwind 3 is retained. Radix owns dialog/popover semantics; Recharts owns chart geometry; DayPicker owns calendar navigation.

Theme: tailwind.config.js and src/AdminTheme.css. Buttons add semantic success/danger hover through data-intent. Legacy workspace classes remain compatibility adapters while consuming these primitives.
