# Avengers Streets

`avengers-streets.json` is a locally hosted adaptation of
[OpenFreeMap Bright](https://tiles.openfreemap.org/styles/bright), downloaded
2026-10-21. Changed land/water/building/road colours, Vietnamese-first labels,
regular fonts and reduced minor POIs. It is not a Google Maps style or service.

Upstream: [OpenFreeMap styles](https://github.com/hyperknot/openfreemap-styles),
[OSM Bright GL](https://github.com/openmaptiles/osm-bright-gl-style), originally
derived from Mapbox Open Styles. Code: BSD-3-Clause; design: CC BY 4.0.
Retained licences: `LICENSE-OpenFreeMap.md`, `LICENSE-Bright.md`.

Tiles/sprites/glyphs remain served by OpenFreeMap. Data: OpenStreetMap;
schema: OpenMapTiles. The map preserves their native source attribution.
Custom style attribution is linked from the map footer.
